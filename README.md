# GnuConvert Accounting Automation Tool

A desktop application written in C# (WPF) that automates accounting workflows for accounting offices.  
The system focuses on converting invoices and bank transactions into a format that can be directly imported into the RLB accounting software, reducing manual bookkeeping work and human errors.

The long-term goal of the project is to support intelligent general ledger account matching using machine learning.

This repository is also intended to serve as a professional portfolio project, demonstrating clean architecture, disciplined Git workflow, and production-oriented development practices.

---

## Features

- Invoice conversion into RLB-compatible CSV format  
- Bank statement (CSV) import and processing  
- General ledger account number validation and normalization  
- User-friendly error handling and validation messages  
- Modular and extensible architecture  


Planned:
- AI-assisted general ledger account prediction  
- Training data collection pipeline  
- Model training and evaluation workflow  
- Assisted decision-making with human validation

---

## Tech Stack

- Language: C#  
- UI: WPF  
- Architecture: MVVM  
- Platform: .NET  
- Accounting integration: RLB accounting software (CSV-based import)  
- Machine Learning (planned): ML.NET
